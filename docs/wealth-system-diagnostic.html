5. Why AI free research is not working

  1. The run reaches the debate model stage and fails because the preview has no usable AI Gateway configuration.
  2. The primary code path reads a saved free-model key or AI_GATEWAY_API_KEY. It calls Vercel AI Gateway using the Nemotron Free model.
  3. Groq fallback is not automatic unless both a Groq key and the zero-data-retention confirmation are present.
  4. The Provider Health code treats a deployment OIDC token as a possible gateway configuration, but the debate caller's primary key lookup shown in source checks the saved key and AI_GATEWAY_API_KEY. Verify this discrepancy before relying on OIDC as a fallback.
  5. Even after the model is configured, agent web search is a separate capability and requires Tavily. No Tavily key means the search tool is omitted from the agent's tool list.
  6. Research collection has no recorded successful run and the source table has no rows in this DB snapshot, so the model also lacks a fresh evidence pack.
